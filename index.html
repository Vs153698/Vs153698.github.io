State Persistence & Reactivity

Event-driven in-memory updates vs re-running whole scripts from line 1

Pyvello Next-Gen Architecture
# Pyvello: In-Memory Event Dispatch (<0.45ms)
import pyvello as ui

counter = 0

@ui.button("Increment").on_click
def on_click():
    global counter
    # Only this callback executes in-memory!
    # Script NEVER re-runs top-to-bottom.
    counter += 1
    ui.toast(f"Updated counter to {counter}", type="success")

with ui.App(title="Swarm Hub"):
    ui.title("Reactive Swarm Operations")
    ui.metric("Counter State", f"{counter}")
Persistent Python process memory. Zero reload flicker. Sub-millisecond JSON-RPC diffing.
